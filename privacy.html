Privacy Policy

AtibaExplainerVideos · Effective date: November 16, 2026

1. Who operates this application

AtibaExplainerVideos is a personal automation tool operated by the owner of the AtibaExplainerVideos YouTube channel. It is used only with the owner's own Google account and YouTube channel. It is not offered to, and does not collect data from, other users or viewers.

2. Google user data the application accesses

The application connects to the YouTube Data API through Google OAuth and requests these permissions:

  • youtube.upload – to upload videos produced by the application to the owner's channel (always as private) and to set their thumbnail.
  • youtube.force-ssl – to read and update the privacy status of videos the application uploaded, only after the owner has reviewed and approved a video.
  • youtube.readonly – to read the channel's name and the titles of its most recent uploads (up to 50), which is used to avoid uploading the same video twice.

The application does not access viewers' data, comments, subscribers, analytics, or any other Google services.

3. How the data is used

  • The channel name is used only to confirm that the correct channel is connected.
  • Recent upload titles are compared in memory with the title of a new video to prevent duplicates; they are not stored.
  • For videos the application uploads, it keeps a log in the owner's private code repository containing the video ID, title, upload time and privacy status, so the same video is never uploaded twice.

Google user data is not sold, not used for advertising, and not shared with third parties. The application also uses Google Gemini (to draft and check scripts) and ElevenLabs (to create narration); these services receive only public historical source text and the video script, not YouTube account data.

4. Storage of credentials

The OAuth refresh token is stored in a local file on the owner's computer that is excluded from version control, and as an encrypted secret in the owner's private GitHub repository settings, which the automated daily job uses. It is kept until the owner revokes access or deletes it.

5. Revoking access

Access can be revoked at any time on the Google Account permissions page: myaccount.google.com/permissions. After revocation the application can no longer access the YouTube channel.

6. Google and YouTube policies

This application uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

7. Changes and contact

If this policy changes, the updated version will be published on this page with a new effective date. Questions can be sent through github.com/atillabagci99.
